# 🍞 BreadMBTI - 나는 어떤 성심당 빵일까?

성심당 빵과 MBTI를 결합한 재미있는 성격 테스트 웹 애플리케이션입니다.

🌐 **배포 주소**: [https://www.bakerytrip.my/](https://www.bakerytrip.my/)

> **⚠️ 주의**: 이 프로젝트는 비공식 팬사이트이며, 성심당과 무관합니다.

## ✨ 기능 소개

### 1. MBTI 테스트
- 12개의 재미있는 질문으로 당신의 MBTI를 측정합니다
- 결과에 따라 16가지 성심당 빵 중 하나를 추천합니다
- 카카오톡 공유 기능으로 결과를 친구들과 공유할 수 있습니다

### 2. 빵집 지도
- 대전광역시의 '2025 빵산책 in 대전' 지도를 제공합니다
- 각 빵집의 위치와 정보를 확인할 수 있습니다

### 3. 오늘의 빵 담당자
- **핀볼룰렛**: Box2D 물리 엔진을 사용한 고급 룰렛
- **간단한 룰렛**: 빠르고 간단한 원판 돌림판
- 친구들과 함께 빵 담당자를 공정하게 뽑을 수 있습니다

## 🛠 기술 스택

- **프레임워크**: React 18.3.1
- **언어**: TypeScript 5.5.3
- **빌드 도구**: Vite 7.1.5
- **스타일링**: Tailwind CSS 3.4.1
- **아이콘**: Lucide React 0.344.0
- **물리 엔진**: Box2D WASM 7.0.0 (핀볼룰렛용)
- **공유 기능**: 카카오톡 SDK

## 🚀 시작하기

### 필수 요구사항

- Node.js 18.x 이상
- npm 또는 yarn

### 설치 및 실행

1. **저장소 클론**
```bash
git clone <repository-url>
cd breadmbti
```

2. **의존성 설치**
```bash
npm install
```

3. **개발 서버 실행**
```bash
npm run dev
```

4. **브라우저에서 확인**
   - 개발 서버가 실행되면 터미널에 표시된 URL로 접속하세요 (기본: `http://localhost:5173`)

### 빌드

프로덕션 빌드를 생성하려면:

```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

### 미리보기

빌드된 파일을 미리보려면:

```bash
npm run preview
```

## 🎯 주요 기능

### MBTI 테스트

- **12개의 질문**: 빵과 관련된 재미있는 시나리오 기반 질문
- **16가지 결과**: MBTI 16가지 유형에 대응하는 성심당 빵
- **이미지 프리로딩**: 결과 이미지 미리 로드로 부드러운 사용자 경험
- **공유 기능**: 카카오톡 공유 및 Web Share API 지원

### 빵집 지도

- 대전광역시 빵산책 지도 표시
- 마커 클릭 시 상세 정보 모달
- 네이버 지도 연동 (길찾기)
- 전화 연결 기능

### 룰렛 픽커

#### 핀볼룰렛
- Box2D 물리 엔진 기반
- 실제 물리 시뮬레이션으로 공정한 결과
- 고급 그래픽 효과

#### 간단한 룰렛
- SVG 기반 원판 돌림판
- 빠른 실행 속도
- 모바일 최적화

## 🔧 환경 변수 설정

카카오톡 공유 기능을 사용하려면 환경 변수를 설정해야 합니다.

`.env` 파일을 프로젝트 루트에 생성하고 다음 내용을 추가하세요:

```env
VITE_KAKAO_APP_KEY=your_kakao_app_key_here
```

카카오 앱 키는 [카카오 개발자 콘솔](https://developers.kakao.com/)에서 발급받을 수 있습니다.

> **참고**: 환경 변수가 설정되지 않아도 앱은 정상적으로 작동하지만, 카카오톡 공유 기능만 사용할 수 없습니다.

### Vercel 배포

1. Vercel에 프로젝트를 연결합니다
